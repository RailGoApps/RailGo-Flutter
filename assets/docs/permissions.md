# RailGo 权限说明

**适用软件：RailGo-Flutter（iOS / Android / HarmonyOS）**

## 总则

1. **所有权限均为可选权限。** 拒绝授权任何权限均不影响本软件核心查询功能的使用——**车站查询、车次查询、动车组查询无需任何权限**。
2. 每项权限均对应特定功能（测速、证件库、行程提醒等）。拒绝授权后，相应功能按下列各项所述方案**降级运行**，而非完全不可用。
3. 涉及敏感个人信息（证件信息、生物识别）的功能，启用时将另行请求您的**单独同意**，详见《隐私政策》（privacy.md）。
4. 您可随时在系统设置中授予、收回或调整权限；本软件不会反复弹出权限请求。

## 一、位置权限（前台）

【用途】用于实时测速与地图定位展示。

【数据处理方式】位置数据仅在内存中实时使用（计算当前速度、地图定位展示），**不存储、不上传**。

【拒绝后的降级方案】测速页显示未授权提示；您可改用**传感器辅助模式**——通过加速度计积分估算速度，界面标注"卫星信号弱"，以提示数据精度受限。

## 二、生物识别权限（Face ID / 指纹 / 鸿蒙人脸识别）

【用途】用于证件库的解锁验证。

【数据处理方式】仅调用操作系统本地校验 API，获取"通过 / 失败"布尔结果；**不采集、不留存任何生物特征或其模板**。

【拒绝后的降级方案】降级为 **6 位数字 PIN 码或手势密码**（均为本地校验），证件库加密功能不受影响。

## 三、相机权限

【用途】用于拍摄证件图片，作为证件库记录的附图。

【数据处理方式】拍摄的图片仅保存在设备本地，并随证件记录一同以**国密 SM4 算法加密**存储，**不上传**。

【拒绝后的降级方案】可从相册选择已有图片，或直接跳过证件图片（证件记录不强制附图）。

## 四、传感器权限（加速度计 / 陀螺仪）

【用途】用于卫星定位不可用时的辅助测速（测速兜底方案）。

【数据处理方式】传感器数据仅在内存中实时积分运算以估算瞬时速度，**不存储、不上传**。

【拒绝 / 不可用后的降级方案】测速功能退化为**纯时刻表时间驱动显示**（按车次时刻表推算预计运行进度）。

## 五、通知权限

【用途】用于行程实时活动：Android 前台服务常驻通知、iOS 灵动岛与锁屏组件、鸿蒙实况窗。

【数据处理方式】通知内容仅由本地行程数据在设备端生成，不产生任何额外的数据收集。

【拒绝后的降级方案】仅在应用内展示行程状态，不显示系统级通知、常驻组件与实时活动。

## 数据安全承诺

- 任何权限产生的数据均不上传服务器，详见《隐私政策》；
- 涉及敏感个人信息的处理均遵循单独同意机制；
- 如遇与本文说明不符的权限请求或数据行为，请通过 **services@railgo.dev** 向我们反馈。
