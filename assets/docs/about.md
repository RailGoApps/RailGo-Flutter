# 关于 RailGo

## 项目介绍

**RailGo** 是一款现代化、专业的铁路查询工具。本应用为 **RailGo 的 Flutter 版本（RailGo-Flutter）**，由 RailGo Contributors 将原 uni-app 版本重写为 Flutter 而来，**iOS / Android / HarmonyOS 三端自适应**，一套代码、多端一致体验。

RailGo-Flutter 提供车站查询、车次查询、动车组（配属 / 车型）查询、实时测速、行程实时活动、本地加密证件库等功能；您的全部敏感数据仅在设备本地处理（详见《隐私政策》）。

开源仓库：<https://github.com/RailGoApps/RailGo-Flutter>
