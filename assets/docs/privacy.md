# RailGo 隐私政策

**适用软件：RailGo-Flutter（iOS / Android / HarmonyOS）**
**版权所有：Copyright (c) 2025-present RailGo Contributors**

## 引言

RailGo Contributors（以下简称"我们"）高度重视您的个人信息与隐私保护。本政策依据《中华人民共和国个人信息保护法》（PIPL）及《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规制定，说明本软件如何收集、使用、存储与保护您的信息。

**本政策的核心原则：您的个人敏感信息默认且仅在您的设备本地处理——不上传、不收集、不掌控。**

请您仔细阅读并充分理解本政策，特别是粗体标注的敏感个人信息处理规则与单独同意机制。您使用本软件，即表示同意本政策所述的信息处理活动；涉及敏感个人信息的处理，我们将在相应功能启用时另行取得您的单独同意。

## 一、我们收集的信息与处理目的

**本软件的全部个人信息处理活动均在您的设备本地完成：**

| 信息类别 | 处理目的 | 处理方式与存储位置 | 是否离开您的设备 |
| --- | --- | --- | --- |
| 证件信息（证件照片、证件号码等） | 构建您的本地证件库，供离线查看 | 使用**国密 SM4 算法**加密后，存储于设备本地安全存储区 | 否，绝不上传 |
| 生物识别（Face ID / 指纹 / 鸿蒙人脸） | 证件库解锁验证 | 仅调用系统本地校验，获取"通过/失败"结果；**不采集、不留存任何生物特征模板** | 否 |
| 位置信息 | 实时测速与地图定位展示 | 仅在内存中实时使用，不存储、不上传 | 否 |
| 传感器数据（加速度计 / 陀螺仪） | 卫星定位不可用时的辅助测速（兜底） | 仅在内存中实时积分运算，不存储、不上传 | 否 |
| 查询历史（车站 / 车次 / 动车组查询记录） | 供您回溯查看历史查询 | 存储于设备本地数据库 | 否 |

除上表所列信息外，本软件不收集您的通讯录、相册、剪贴板、短信、通话记录、广告标识符等任何其他个人信息。

## 二、敏感个人信息处理规则与单独同意机制

2.1 依据 PIPL，**证件信息（涉及个人身份）、生物识别信息属于敏感个人信息**。本软件处理敏感个人信息，均以**取得您的单独同意**为前提，并限于特定目的与最小必要范围。

2.2 单独同意的取得方式：

- 您首次启用证件库并录入证件信息时，本软件将**单独**弹窗告知处理目的、处理方式与存储范围，经您明示同意后方才启用；
- 您首次启用生物识别解锁时，本软件将**再次单独**请求您的同意；
- 您有权拒绝上述同意，**拒绝不影响您使用本软件的核心查询功能**（详见《权限说明》permissions.md）。

2.3 保护措施：敏感个人信息采用国密 SM4 算法加密存储于设备本地，密钥保管于设备系统安全存储区（iOS Keychain / Android Keystore / 鸿蒙安全存储），全程不经过任何网络传输。

2.4 我们除实现证件库加密存储与解锁验证外，不设定任何其他敏感个人信息处理目的；不满十四周岁未成年人个人信息的处理规则见第六条。

## 三、数据本地化与 SM4 加密说明

3.1 本软件默认采用本地化数据处理策略：您的证件信息、生物特征数据**仅存储于您的设备本地**，使用**国密 SM4 算法**加密，**不会上传至任何服务器**。

3.2 生物识别仅调用操作系统的本地校验能力，本软件**不留存任何生物特征模板或样本**。

3.3 卸载本软件或在应用内执行清除数据操作后，上述本地数据将被彻底删除且不可恢复。

## 四、跨境数据传输条款

4.1 您知悉并同意，为保障软件的正常运行、功能迭代及基础数据采集，部分已进行去标识化（去密）处理的**非敏感**数据，可能会被传输至泛中华地区（主要为中国内地）的服务器进行处理、存储或分析。前述去标识化数据**不包含**您的证件信息、生物特征数据、精确位置轨迹等敏感个人信息。

4.2 完整的《数据跨境传输与法律合规声明》以《最终用户许可协议》（eula.md）所载内容为准，本条系对该声明的引述与摘要。

4.3 本软件未适配欧盟 GDPR、美国 CCPA/CPRA 等对数据跨境传输有严格限制的法域的特定法律要求；相关地域限制以《最终用户许可协议》为准。

## 五、第三方数据服务说明

5.1 本软件的查询数据与图片资源来自下列第三方数据服务。各服务仅能获得其完成网络通信所必需的信息（如查询请求参数、常规网络层技术信息），**无法获得您的本地敏感数据**：

| 第三方服务 | 提供的内容 | 其可能获得的数据 |
| --- | --- | --- |
| RailGo API（railgo.dev / api.railgo.dev） | 车站、车次、时刻、动车组等查询数据 | 查询请求参数（车站 / 车次 / 车组编号等非个人内容）及必要网络通信信息（如 IP 地址、User-Agent）等常规技术信息 |
| MoeFactory | 动车组配属数据 | 数据 / 图片请求的常规网络技术信息 |
| tp.railgo.zenglingkun.cn | 车型图众包图片 | 图片请求的常规网络技术信息 |
| train.idcmoss.cn | 车模图库图片 | 图片请求的常规网络技术信息 |
| 天地图 | 地图瓦片 | 地图瓦片请求的常规网络技术信息及瓦片坐标（用于地图渲染） |

5.2 上述第三方服务各自的数据处理活动遵循其自身的隐私政策与服务条款。依据 <https://api.railgo.dev/llms.txt>：RailGo API 数据不得用于商业用途、不得公开中转，使用时须标注来源。

## 六、未成年人条款

6.1 本软件面向一般铁路信息爱好者，**不以未成年人为目标用户，不主动收集未成年人个人信息**。

6.2 我们不处理不满十四周岁儿童的敏感个人信息。若您是未成年人的监护人并发现被监护人使用了证件库等敏感功能，请引导其停止使用并删除本地数据；未成年人使用本软件的，应在监护人指导下进行。

6.3 监护人有权拒绝或撤回对被监护人信息处理的同意，可直接在设备端删除相关数据或卸载本软件，操作即时生效。

## 七、您的权利

依据 PIPL，您对您的个人信息享有查阅、复制、更正、删除、撤回同意等权利。**您的全部数据均存储于设备本地，您可以随时自主行使，无需申请：**

- **查阅 / 复制**：在应用内查看证件库、查询历史等本地数据；
- **更正**：在应用内编辑或重新录入证件信息；
- **删除**：在应用内删除单条记录，或通过清除本地数据 / 卸载应用一次性删除全部本地数据，删除即刻彻底生效；
- **撤回同意**：在系统设置中关闭相应权限，或在应用内停用相应功能（如关闭生物识别解锁、清空查询历史），即视为撤回对应同意；撤回同意不影响撤回前基于您同意已进行的处理；
- **注销 / 退出**：本软件无账号体系，卸载应用即等同于注销。

若您认为我们对个人信息的处理损害了您的合法权益，可通过 **services@railgo.dev** 向我们反映，我们将及时核实处理；您也有权向网信部门等履行个人信息保护职责的部门投诉、举报。

## 八、政策更新

8.1 我们可能适时修订本政策。修订后的政策随软件版本一同发布，并通过应用内公告、"关于"页等适当方式向您告知。

8.2 涉及敏感个人信息处理目的、处理方式等重大变更的，我们将重新请求您的单独同意。

8.3 本政策与《最终用户许可协议》（eula.md）配套适用；如有不一致，以《最终用户许可协议》为准。
